 # C Programming Repository

 A collection of C programs and exercises for learning and practicing the language. Each source file can be compiled and run independently unless its comments or related files specify otherwise.

 ## Requirements

 - A C compiler, such as GCC or Clang
 - A terminal or command prompt

 ## Compile and run

 From the directory containing a `.c` file, compile it with GCC:

 ```sh
 gcc filename.c -o program
 ```

 Run the executable:

 ```sh
 ./program
 ```

 On Windows, run `program.exe` instead. If a program uses multiple source files, include them all in the compile command.

 ## Using the programs

 Browse the source files and replace `filename.c` in the commands above with the desired file. Some programs may request input in the terminal; follow any prompts they display. Check each source file for additional requirements.

 ## Contributing

 Keep examples focused, use clear names and helpful comments, and verify that changed programs compile before submitting them.
